# Como o tl;dv monta as páginas de comparação

As páginas de comparação do tl;dv moram dentro do blog, não numa pasta própria. O mesmo molde serve para o comparativo do próprio produto contra um rival e para o comparativo entre dois terceiros. Nos dois exemplos lidos de [Fathom contra Grain](https://tldv.io/blog/fathom-vs-grain/) e [Fathom contra Otter](https://tldv.io/blog/fathom-vs-otter/), nenhum dos dois produtos comparados é o tl;dv: o blog usa o rival como isca de busca e entrega o leitor ao produto próprio no fim da página.

## O molde repetido

As duas páginas têm a mesma sequência de blocos, só trocando os nomes:

1. Um bloco "tl;dr" logo no começo.
2. Uma seção com título "Fathom vs X: 12 Factors to Consider While Choosing", que compara os dois produtos por fatores numerados.
3. Uma seção "Verdict: Fathom vs X – Which One Is the Best?".
4. Um bloco "Meet your AI Meeting Agents for Sales", que apresenta o tl;dv como terceira opção.
5. "Related posts" e, por último, uma chamada "Running late to your next meeting?".

O título de cada seção é montado com o nome dos dois produtos e uma pergunta de decisão ("which one is the best"), o que cobre as buscas "A vs B" e "A ou B".

## Onde pede a conversão

A conversão não está no veredito: ele escolhe entre os dois rivais. O pedido de cadastro aparece depois dele, no bloco para vendas, e de novo na chamada final. As duas páginas apontam para o app do tl;dv e, na primeira, também para a página de preços.

## O que isso significa para a Cally

Quem compara ferramentas de ata de reunião aceita um comparativo que não cita o produto até o fim. Para a Cally, o molde que vale copiar é o veredito honesto entre dois concorrentes seguido de uma chamada para o produto, desde que a chamada diga o que a Cally faz de diferente (organizar a gravação no projeto certo a partir da Google Agenda).
